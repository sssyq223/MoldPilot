# Quick Prompts from PiDeck

常用的快捷提示词集合，从 PiDeck 导入。

## 使用方式

直接在对话中输入 `/quick-prompts` 然后选择需要的提示词。

## 提示词列表

### 基础交互
- 你好，你是什么模型
- 继续
- 用中文回答我

### Git 操作
- 提交
- 推送
- 提交推送
- review 一下这个 commit

### 代码规范
- 给出完整可运行的文件
- 只改我提到的部分，不要顺手改其它代码
- 参考项目里已有的实现和代码风格
- 不要添加不必要的注释

### 问题排查
- 请仔细思考，确保正确且完整实现
- 再确认一下
- 还是不对，请重新排查
- 还是无法运行，先看报错再修
- 先检索查证再回答，不要凭猜测下结论

### 工作流程
- 先别写代码，先梳理方案
- 随便用ask提问我
