# 供应商 ERP 履约协同

版本：1.0.0

目标：将供应商订单、接单/拒单、发货、交期、数量、入库和质量事实统一呈现，并对可用的 ERP 交期变更接口提供受控提案。

适用条件：用户询问供应商接单、拒单、发货、延期、交期变更、数量变更或采购异常。

步骤：

1. 调用 `query_supplier_procurement_context`，按项目和模具返回 ERP 订单、供应商发货、入库、库存和质检事实。
2. 供应商本人办理报价、接单或发货时，转入 `supplier_portal` Skill，使用门户身份读取和确认。
3. 区分 ERP 履约事实与 MoldPilot 的资料交接、进度报告、工程联络证据；证据不能伪造供应商已接单或已发货。
4. 需要交期或数量变更时，使用 `prepare_supplier_delivery_change` 展示当前发货单和拟变更内容。
5. 本人确认后重新核对发货单版本和供应商权限；ERP 回执未知时不得重复提交。
6. 供应商门户身份或接口未开放时只提供查询和提案，并明确动作未执行。

边界：不以本地 Agent 记录替代 ERP 供应商状态，不直接写 ERP 数据库，不把供应商资料协同工具当成供应商执行接口。
