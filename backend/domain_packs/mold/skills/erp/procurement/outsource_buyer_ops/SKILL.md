# 委外采购办理

只办理**委外采购员**在零件/模具委外采购支线上的动作：填我方报价与区间、选商发询价、超区间成交价、拒单后重选。不代办审批、接单、仓管、质检。

## 本角色可办阶段

| 阶段 | 办理工具 |
| --- | --- |
| 待采购填报价 | `prepare_erp_outsource_buyer_quote` |
| 待发询价 | `prepare_erp_outsource_inquiry_send` |
| 待下单 | `prepare_erp_outsource_final_deal` |
| 全部拒单 / 拒单后 | `prepare_erp_outsource_reselect` |

工序委外不走填价/询价/成交价。用户拿工序单来办这些动作时说明原因，不 prepare。

## 识别到填报价必须弹出报价表

用户本轮是在**填我方报价 / 填报价 / 填价格 / 报报价 / 准备填写我方报价**（含「出确认卡」），并且金额已给出时：

1. **先锁定身份，再出表。** 必须确认模具号，并且确认订单号。待采购填报价尚未下单时，订单号按「尚未下单」，改用模具号 + 批次号 + 零件号锁定同一行。用户说「第1行」或「待排列第一 / 待排第一」时按当前待填价看板该行的零件号锁定，不要再问一遍零件。同一批次有 PH-01 / PU-01 / UB-01 多行时，只说模具+P1 不够，必须带零件号或第N行。缺模具号，或既没有订单号、又凑不齐批次号+零件号时：只澄清要哪一单，**禁止**只回待办看板表，也**禁止** prepare。
2. **身份锁定后立刻**调用 `prepare_erp_outsource_buyer_quote`，弹出与 ERP 填价页同类的**报价确认表**（核算价、我方报价、直接接单上限，以及订单号/模具号/批次号/零件）。这就是确认卡。不要用 Markdown 表格代替确认卡，不要只 query 看板。
3. 总价格填 `our_quote_amount`，上限填 `auto_accept_max_amount`。用户点名零件时必须带 `part`（如 PH-01）。同一模具同一批次常有多张询价，只传模具+P1 会命中多张。
4. 禁止编造 `prepare_project_quote`。禁止口头复述金额当确认。本人在确认卡上确认后才写入 ERP。

## 工作流

```text
先锁定 模具号 +（订单号 或 批次号+零件号）+ 当前分站
  → 识别到填报价且金额齐全
  → prepare_erp_outsource_buyer_quote 弹出报价表确认卡
  → 本人确认后才调 ERP
```

只问数量或待办时先 query，不要 prepare。看板已经列出待填价行、用户已点名零件并给出报价和上限后，立刻 prepare，不要再调 `query_erp_outsource_order_progress`，不要再画一遍待办表。同一模具多单未点名零件时列出候选的订单号、模具号、批次号、零件号，等用户选定后再 prepare。尚未下单时用单一批次号；合并多批次的询价要用表格里的完整批次号。用户说第N行时，按当前待填价看板该行的完整批次号+零件号锁定，不要只用口里的 P1。禁止使用内部数字 id。填价确认写入后，当前分站才会变成待发询价；选加工商、发询价是下一步，另走 `prepare_erp_outsource_inquiry_send`。用户追问上一轮失败原因时，用已有查询结果解释，不要再查一遍整表。

1. 状态不对、缺金额时只澄清，不 prepare。
2. 确认卡必须写清订单号（或尚未下单）、模具号、批次号、零件、报价表金额。用户说「这单发询价 / 待发询价的这单发送询价 / 第一行发送询价 / 确认办理发送询价」且未点名加工商时，立刻 `prepare_erp_outsource_inquiry_send` 并**省略 suppliers**，用该单 ERP 已匹配名单；本轮已点名待发询价或「这单」时，不要沿用上一轮填价的批次号。「第一行」按当前待发询价第一张锁定，不要按整表待填价第一行。禁止再口头问「确认下一步办理」，禁止编造「华兴机械」等名称，禁止把「和兴」改写成「华兴」。用户点名时必须用查询结果里的编码或全称。禁止内部数字 id。用户否认则停。
3. 禁止口头宣布已写入。以确认卡回执和 ERP 返回为准。

## 跨角色交接

- 加工商报价后：区间内 ERP 免审定标，单子到待接单（加工商办理）。超区间才填成交价，再等主管王群、总经理李辉审批。
- 零件/模具拒单后用重选 + 发询价。工序拒单由 ERP 自动转下一家；只有队列耗尽才重派。
- 不代办加工商报价/接单，不代批下单审批。

## 边界

采购主管/总经理审批、加工商报价/接单、仓管发料入库、质检不在本 Skill。整套委外合同用 `full_outsource_review`。
