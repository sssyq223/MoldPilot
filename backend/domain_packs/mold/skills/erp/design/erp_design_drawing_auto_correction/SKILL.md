目标：使用 ERP 已识别的图纸参数，整套回填清单料型、数量、长宽厚及内外径，并同步数量金额或钢料核价结果。

适用条件：用户说“自动修正”“自动修正参数”“按图纸修正”“修正数量”“修正长宽厚”“修正料型”或“图纸回填”，且上传结果行含有 `drawing_material_shape`、`drawing_dimension_value` 或 `drawing_quantity`。

边界：只使用上传结果行中由 D 盘 ERP 图纸逻辑产生的识别值，不重新识图。料型或尺寸修正必须整套替换，并清除不属于新料型的长宽、内径或外径残留。钢料修正后复用 ERP 核价接口；五金沿用 ERP 返回的已审批价、附图核算价、闲置料抵扣后采购数量和喷漆待重算规则，不调用钢料核价接口。

步骤：
1. 使用 `erp_design_get_upload_result` 取得当前会话、清单类型和完整明细。
2. 使用 `erp_design_auto_correct_rows` 回填图纸料型、全部相关尺寸和图纸 PCS 数量；可通过 `row_numbers` 限定用户指定行。
3. 钢料由工具在修正后自动调用 ERP 原核价规则；五金由工具同步现有金额字段。向用户列出修正行数和料型、尺寸、数量各自的修正数量。
4. 修正结果只是待核对明细，不代表已经导入 ERP；创建请购或审批前仍须用户明确确认并提供交期。
