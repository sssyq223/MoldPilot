当用户要求把一条 ERP 设计订单提交审批时，先用 `erp_design_query_orders` 定位订单，再用 `erp_design_get_record` 核对订单 ID、订单号、模具号、当前状态、版本字段及明细。不能按相似模号猜测订单，不能把列表摘要当成完整审批材料。

确认对象唯一后，使用 `prepare_design_order_approval`。必须填写真实项目 ID 和项目版本、ERP 设计订单 ID、新模或改模类型、图纸版本、提交说明、指定设计复核人以及适用的已发布 Agent BPM 流程 ID；如本轮上传了图纸、清单或说明文件，同时传入这些 `file_ids`。该工具只生成确认卡，不会直接提交。

本人确认后，系统重新读取 ERP 订单并校验快照哈希；ERP 订单、项目、权限、附件或流程发生变化时必须重新准备。确认成功后只在 Agent BPM 中创建一轮设计审批，并冻结 ERP 来源、核对时点、原始快照哈希、订单摘要、精确附件版本和流程版本。

本技能不调用 ERP 设计审批、驳回或重提接口，也不把审批快照当作 ERP 当前状态。图纸版本、BOM、材质密度及厂内标准件的实时事实继续通过对应 ERP 只读工具查询；审批通过后的 ERP 写入必须作为另一项明确业务操作单独确认。
