# ERP 解析清单与业务上下文核对

版本：1.0.0，只读复用 ERP 现有能力。

当用户追问“刚才解析的清单、这个附件、上传结果、清单类型、材料类型、订单类型、设计类型、行数、模具号”时，先调用 `erp_design_get_upload_result`。当前会话已经有解析记录时省略 `session_id`，由宿主绑定最近一次本人解析会话；不能猜测或复用其他会话的会话号。

解析结果中的 `sheetType`、文件名、模具号、行数和 ERP 返回的明细是当前可见事实。钢料/五金是清单类型；新模/改模是业务订单类型，二者不能混为一谈。没有 ERP 回执的字段不得从文件名或模型推断。

当用户询问“交期、客户交期、承诺交期、预计交期”时，先取得解析结果中的准确模具号或订单线索，再按数据归属查询：ERP 设计订单使用 `erp_design_query_orders`，本项目计划/客户交期使用 `query_project_plan_context`。必须说明来源、查询时点和字段语义；解析清单本身没有交期字段时，明确说明“解析结果未提供交期”，不能把上传日期、解析时间或导入表单待填的 `expected_date` 当成交期。

只读核对不导入、不修改 ERP 订单、不调整计划、不提交审批。ERP 或本项目没有对应记录时，说明未查到的来源和缺口，不用另一来源的旧快照替代当前事实。
