# 制造工序与质检上下文核对

版本：1.0.0，新项目独立编写。

当用户询问某项目的加工工序、现场报工、实际耗时、工序检验、质量问题、整改复检、局部委外交接、装配或试模前置条件时，先调用 `query_manufacturing_quality_context`。

工具返回当前可见的项目计划任务、任务实际开始/完成日期、设计 BOM 路线、内部加工/采购/委外路线、装配任务、试模记录和工程联络异常上下文。只能说“当前已见到/未见到”对应事实；未见到不能解释为企业没有发生，可能是 ERP 制造模块尚未接入、未授权、未确认或线索不唯一。

同时读取 `analysis.erp_manufacturing_execution` 中的 ERP 制造工单、工序报工、工单报工和 `analysis.erp_quality_inspections` 中的质检任务/结果只读事实。ERP 返回的 `source_ref`、`source_endpoint` 和 `as_of` 是原系统核对入口；ERP 事实不会写入 Agent 计划或本地工单。ERP 未配置、未登录或调用失败时必须保留原状态。

计划任务的实际开始/完成日期只能作为当前 Agent 可见的执行事实，不等同于完整现场报工、工时、设备、班组或检验报告。ERP 有待检、合格、部分合格或不合格任务时，必须保留其状态和原系统引用；任务完成或 ERP 质检结果都不能替代 Agent 的整改、复检、入库放行或项目验收。方案审批不等于整改已完成，整改完成也需要独立复检/关闭依据。

内部加工、局部委外、采购收货、装配和试模应分开说明。看到内部加工路线不能声称采购或委外成果已收货；看到装配或试模记录不能声称整套模具已交付合格。

本技能只读，不创建工单、不登记报工、不确认检验、不收货入库、不关闭异常、不修改 ERP 制造数据。需要办理时必须进入对应准备工具、ERP 执行能力或人工确认流程。
