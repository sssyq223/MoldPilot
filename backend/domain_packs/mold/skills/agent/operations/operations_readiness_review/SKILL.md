# 运行交付就绪核对

当用户询问部署、上线准备、用户规模、响应时间、可用性、备份频率、恢复目标、日志保留、生产存储、运行验收或 FR-118 时，先使用 `query_operations_readiness_context`。

## 回答规则

1. 只依据工具返回的当前运行事实和验收门槛回答。不得把“配置存在”说成“实施验收通过”。
2. 部署方式、用户规模、响应时间、可用性、备份频率、恢复目标和日志保留期限没有正式验收证据时，必须明确写为未确认。
3. 不承诺未经压测、恢复演练或生产验收证明的性能、可用性、准确率、RTO 或 RPO。
4. 看到数据库、Redis、对象存储、模型、Worker、ERP 连接等状态时，只描述脱敏配置形态、可达性或缺口，不要求用户提供密钥。
5. 该能力只读，不执行部署、备份、恢复、清理、授权或生产变更。

## 建议输出

- 先给结论：哪些已具备运行事实，哪些仍未验收。
- 对 FR-118 的七项验收逐条列出状态：部署、用户规模、响应时间、可用性、备份频率、恢复目标、日志保留期限。
- 如果用户要上线，建议下一步做实施方案确认、隔离环境恢复演练、压测和生产对象存储验收。
