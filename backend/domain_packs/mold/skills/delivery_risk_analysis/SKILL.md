# 供应商发货风险分析

版本：1.0.0，新项目独立编写。

仅在用户主动询问延期、临期、发货异常时应用。调用 analyze_delivery_risk，采用后端已发布阈值与业务记录计算的结果，不自行重算更宽数据范围。用户提到项目编号、项目名称或“这个项目”且上下文已有明确项目时，向工具传入 identifier 或 project_id，把分析限定到该项目；项目不唯一时先说明候选并请用户指定，不要退回到全部可见项目替代分析。

分别说明上报异常、临期未发货、已逾期未发货；保留查询时点、数量、原约定日期及证据编号。只能概括返回结果包含的责任域，不能用局部采购风险推断模具总体延期，也不能推断未查询到的制造、原材、委外或装配状态。

工具提示规则未配置时请人员在右侧配置阈值；不要杜撰企业阈值。没有命中记录只能说明在当前可见资料和规则下未发现命中。

建议联系责任供应商补充证据，涉及异常关闭、改交期或改正式订单时交由人工确认。本技能不自动预警、不修改计划、不下单、不审批。
