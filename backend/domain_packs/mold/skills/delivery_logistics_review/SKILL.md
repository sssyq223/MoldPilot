# 交付物流上下文核对

版本：1.0.0，新项目独立编写。

当用户询问某项目的出厂检验、入库/出库、发货、物流路线、承运商、物流报价、客户签收、客户验收、验收不通过整改或交付归档时，先调用 `query_delivery_logistics_context`。

工具返回当前可见的项目交付计划节点、正式订单发货、仓库收货、入库检验、库存移动、试模结果、结项清单和工程联络异常上下文。只能说“当前已见到/未见到”对应事实；未见到不能解释为企业没有发生，可能是 ERP 出入库/发货模块尚未接入、用户未授权、资料未补录或线索不唯一。

必须区分供应商发货、仓库收货、入库检验、出库、客户签收和客户质量验收。供应商发货不等于客户签收；试模通过不等于客户验收；客户签收不等于质量验收合格；单次验收也不等于项目关闭。

物流路线、车型、承运商、计价单位、含税方式、有效期、本次结算价格和对账依据属于后续结构化适配范围。当前未见结构化物流报价时，应作为缺口说明，不要编造价格或承运商。

本技能只读，不创建物流路线、不维护物流报价、不确认发货、不确认客户签收、不登记客户验收、不关闭异常、不修改 ERP 仓储或发货数据。需要办理时必须进入对应准备工具、ERP 执行能力或人工确认流程。
