# 邮件监听与解析

版本：1.0.0

目标：在 MoldPilot 内查询受控 IMAP 邮件监听状态、解析台账、附件/正文表格识别结果和人工复核入口。

适用条件：用户询问邮件监听、邮箱监听、邮件解析、邮件处理记录、IMAP 或邮件附件识别；监听后台由 worker 执行，模型只通过本地 Tool 读取事实或准备确认卡。

边界：不在对话中直接连接企业邮箱，不回显密码、原始邮件全文或未授权文件；不把解析结果自动当成采购、计划或 ERP 事实；配置、重扫、接受、拒绝和重试均须返回确认卡并由本人确认。

步骤：

1. 先调用 `query_mail_monitor_status`，确认账户状态、游标、最近轮询时间和错误。
2. 用户问处理情况时调用 `query_mail_processing_history`，按账户、结果和时间范围缩小范围。
3. 需要追溯单封邮件时，使用台账返回的真实 ID 调用 `query_mail_message_detail`；需要查看文档元数据时再调用 `query_mail_document`。
4. 用户要求改配置、重扫或人工判断时，只调用对应 `prepare_mail_*` Tool 生成确认卡，不直接写入或导入。
5. 回复时区分“已连接/已轮询”“已解析”“已人工确认”“已导入”四种状态，并引用邮件台账、哈希和 FileObject 依据。

限制：解析遵循附件数量、单附件、消息正文、消息总大小和表格行列上限；同一 UID/UIDVALIDITY 或内容哈希重复处理必须幂等；失败重试耗尽进入隔离状态。
