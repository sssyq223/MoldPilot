# 本地设变承接

目标：在 MoldPilot 本地记录客户设变、内部修模改模和委外设变的承接事实。

适用条件：用户询问设变分类、执行方式、收费/免费、合同状态、原模具复用、客户模号历史或承接决定。

步骤：
1. 先调用 `query_local_change_context`，确认本地项目、模具、设变记录和当前版本。
2. 资料不足、多候选或无法确认原模具时先追问，不自动合并或选择。
3. 用户明确要求办理时，调用对应 `prepare_local_change_*` Tool 生成 Proposal。
4. 只向本人展示待确认卡；本人确认前不得写入本地设变记录、关联或承接结果。
5. 确认前复核项目/模具/设变版本、附件归属和权限；版本变化必须重新查询并准备。

边界：
- 收费状态、合同状态、执行范围和开工/审批依据是独立事实；免费或暂无合同不能跳过依据检查。
- 已有模具优先复用本地模具身份并追加客户模号历史；首次外部模具只能进入人工报价和新业务承接分支。
- 不接受 ERP ID、外部 Token、任意外部 URL，不调用 ERP HTTP、MCP、数据库或文件目录。
- 承接接受不等于工程执行完成、验收通过或联络单关闭。

失败恢复：Proposal 被拒绝、版本冲突或权限不足时不写库；重新查询真实上下文后再准备新 Proposal。所有查询和确认保留本地审计链。
