# 本地文档模型配置

目标：核对文档识别专用模型引用，不把聊天模型选择误当作 OCR/文档模型切换。

步骤：
1. 调用 `query_model_configuration`，确认公开模型目录、默认模型、文档模型引用和当前 revision。
2. 只有用户明确要求变更文档模型时，准备 `prepare_model_save` 或 `prepare_model_default` Proposal。
3. 本人确认前不写配置；确认时复核模型仍启用、供应商协议兼容且没有被文档任务占用。
4. 版本冲突或模型被使用时停止并要求重新查询，不自动切换到其他模型。

边界：不读取或回显 API Key，不执行 OCR，不承诺模型已经真实调用；只管理本机配置，不调用 ERP 或外部业务系统。
