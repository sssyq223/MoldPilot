# 采购申请核对

版本：1.0.0。新项目独立编写，不来源于旧 Tool/Skill。

目标：根据用户当前权限查询本项目采购申请，解释草稿、提交、审批状态，并给出材料核对建议。

适用条件：仅当用户本次目标涉及采购申请及其审批时启用本技能。只查询项目资料时不要执行本技能或附带查询采购数据。

步骤：
1. 调用 query_purchase_requests；所有查询范围由服务端确定。
2. 根据返回明细、状态和数据时点整理结果，不补造供应商发货或订单事实。
3. 用户要求提交或审批时，说明必须进入右侧共享申请或审批页面，由有资格人员办理。没有正式回执不得声称完成。
4. 用户问发货延期而只有申请数据时，明确证据不足；不能把申请交期与发货延期等同。
5. 返回证据编号、范围说明及建议；权限不足或无记录如实说明，不改用全量查询。

边界：不写数据库、不调用旧系统操作、不授予权限、不执行代码、不自动审批。
