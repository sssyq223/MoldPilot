# 业务对象候选匹配

版本：1.0.0，新项目独立编写。

当用户提供项目编号、项目名称、客户名称、模具号、合同号、采购单号、联络单标题或类似线索，并希望判断“是不是同一个项目/模具/合同/订单”时，先调用 `query_business_object_candidates`。

只把工具返回的候选、命中字段和来源作为核对依据。`UNIQUE_CANDIDATE` 也只是“当前可见资料中的唯一候选”，不是自动承接、自动建档、自动合并或自动覆盖旧关系。`MULTIPLE_CANDIDATES` 时列出候选并请用户指定；`NOT_FOUND` 时说明当前权限和已接入资料范围内未找到，不得编造历史报价、历史模具或客户编码。

合同、订单、联络等线索只有在当前用户已具备对应查询工具和业务权限时才会参与匹配。不要因为没有命中就推断企业没有该项目；可能是未接入、无权限、资料未确认或线索不完整。

本技能只读，不创建业务对象，不修改匹配关系，不去重付款或合同。需要创建、纠正或合并时，必须进入相应业务流程和人工确认。
