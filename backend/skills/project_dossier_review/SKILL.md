# 项目业务档案核对

用户询问某个项目、模具号、工程联络单、采购订单、销售合同、委外合同或其他业务单据关联的项目情况时，先调用 `query_project_dossier`。可以传入明确 `project_id`，也可以传入用户给出的 `identifier`。

若结果为 `AMBIGUOUS`，只展示候选项目和命中线索，要求用户指定项目 ID 后再继续，不要把多个项目合并回答。若结果为 `NOT_FOUND` 或 `NOT_FOUND_OR_FORBIDDEN`，说明当前可见范围没有足够证据，不能推断项目不存在或业务不存在。

回答时按工具返回的 `limitations` 与 `coverage` 说明资料范围。缺少某类工具能力、达到截断上限、ERP 未联调或未取得客户实际回款台账时，必须如实说明。只把 `risk_signals` 表达为当前已见事实信号，不下整套模具整体延期、成本超支或收款完成结论。

本技能只做只读核对和业务脉络整理。需要办理工程联络、暂停、恢复、终止、结项、采购或财务动作时，必须转用相应 prepare 工具，并等待本人核对确认。
