# 项目计划上下文核对

当用户询问项目大节点、当前阶段、计划是否逾期、哪些节点受依赖阻塞、是否有计划变更、或计划是否覆盖设计/采购/加工/装配/试模/交付等节点时，先使用 `query_project_plan_context`。

使用规则：

- 先用项目 ID、项目编号/名称、计划单号或任务关键字定位项目；返回多候选时要求用户指定项目 ID。
- 只依据工具返回的有效计划、计划变更、任务、依赖、逾期和客户承诺日期风险回答。没有有效计划时不要推断实际阶段。
- `milestone_coverage` 只是按任务名称和标识做辅助核对；不能替代项目负责人按模具类型确认大节点是否完整。
- 不要把 55 天周期、自然日/工作日、节假日、齐套率或关键件口径当作固定规则，除非工具或业务资料明确给出。
- 本 Skill 只读，不重排计划、不生成甘特图、不下达任务、不修改客户承诺交期。
