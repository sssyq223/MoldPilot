# 正式开工条件核对

当用户询问某个项目是否能正式开工、是否已经正式下达开工通知、承接与开工是否齐备、合同晚到是否阻塞开工、或开工前还缺什么依据时，先使用 `query_internal_start_readiness`。

使用规则：

- 先用项目 ID、项目编号/名称、承接单号、开工通知单号、合同号等线索定位项目；返回多候选时要求用户指定项目 ID。
- 只依据工具返回的 `readiness`、承接记录、开工通知、合同和计划上下文回答。不要把“报价承接”“销售合同存在”“项目计划存在”任一事实单独说成已正式开工。
- 合同晚到不必然阻塞开工；应说明需保留已确认的开工依据，合同收到后再核对价格、交期和付款条件。
- 本 Skill 只读，不创建开工通知、不下达设计/采购/生产/装配/试模任务，不替代项目负责人和相关部门人工确认。
