# 供应商多模型、模型检测与会话思考档位

## 批准依据与范围

潘总在本轮对话批准：供应商连接与模型条目分离；输入地址/Key 后检测供应商目录，多选添加并允许手动添加；聊天弹层按供应商分组，按模型能力提供思考档位；选择仅影响当前会话后续任务。未授权代改真实凭据、批量付费探测或改变文档 OCR 的固定 GLM 引用。

## 配置模型

继续使用现有本机模型配置 JSON，不新增业务表。v3 文档包含 providers、models、default_model_id。供应商保存协议、地址、凭据、代理、TLS、连接超时；模型条目保存稳定 ID、provider_id、API model ID、显示名、启用状态、输出/上下文预算、最大轮次与思考能力规则。每个供应商的 API model ID 唯一，不把跨供应商同名模型合并。

旧 v2/legacy 读取时只投影，不落盘、不自动合并相同地址/不同账号。原 profile ID 保留为模型条目 ID，供应商 ID 确定性派生，保证 document_model_profile_id 继续指向原 GLM。首次管理员明确保存才写 v3；写入必须检查 revision、跨进程锁及原子替换。旧写接口不得把 v3 降回 v2。Key 不进入前端回显、模型条目、任务快照或日志。

## 模型检测

管理员显式点击检测，由后端请求 OpenAI 兼容 Base URL 下的 /models；Ollama 使用本机 /api/tags。仅取目录，不调用每个模型，不发送业务原文，不自动保存配置或添加全部模型。优先使用本次填写的 Key；仅在目标地址未改变时允许复用已保存 Key。编辑目标地址但留空 Key 时拒绝复用原凭据。

检测请求受地址/协议校验、DNS 地址核验与连接地址固定、TLS 校验、无重定向、连接/读取时限、响应体/模型数量上限和并发限制保护。公网 HTTPS 不允许解析到私网、回环、链路本地/元数据地址；保留已有显式受信内网 HTTP（无 bearer）及 Ollama 回环例外。复用已配置代理/TLS，不因检测失败关闭验证。

返回模型 ID 去重列表、已获取数量、是否完整、检测时间；供应商分页/截断时不宣称总数已知。401/403、404、不合法响应、超时及限流分别给出安全错误码，不回传上游正文。目录不支持时可手动添加。刷新目录不删除已配置模型；列表成功不等于模型可调用，更不等于支持 Agent 工具/思考。单模型合成请求验证另设显式操作，并提示可能计费。

## 能力与思考

能力规则由后端管理，按模型和供应商协议确定；未知模型不猜测能力。GLM-5.3-Flash 既有证据支持 low/high/max，不支持关闭 thinking。其他模型只有验证过对应协议后才开放控制。目录结果不自动填充上下文上限、工具能力或思考档位。Ollama 的 think 参数与 OpenAI 风格 reasoning_effort 独立适配，不靠改 temperature/max_tokens 模拟。实现提供管理员显式声明的原生 OpenAI 推理、Ollama 开关/档位模板，标记 administrator_declared，不把它当自动探测证明。原生 OpenAI 推理模板用 max_completion_tokens 且不附带固定 temperature，避免传统参数与推理模型协议冲突；GLM 和传统兼容调用保持原请求形状。输出预算仍遵循既有 8192 上限，不自动提升额度。

## 任务与权限

设置页仍由超级管理员管理连接/模型。首版不扩大普通用户模型切换权限；普通用户保持既有默认模型使用边界，不能传入任意 profile 或 endpoint。模型选择和思考档位属于会话偏好，发起任务时后端校验并固定模型 ID、模型路由身份、有效档位和预算；不保存 Key 或包含 Key 的 config_version。Worker 按领取任务的固定配置解析服务器端凭据。同一任务工具轮次、重试和审批续办沿用选择，不能从全局激活模型漂移。旧 Run 首次解析时走明确兼容路径并固化，不假称历史已经固定。

任务宿主状态须由服务端保护，Harness checkpoint 不得覆盖。默认配置仅为未选模型的新任务提供默认值。模型/供应商停用、删除、路由变更后，任务领取或恢复时明确阻断，不静默换模型。已经执行中的任务不因聊天框切换或默认配置调整而重选模型；紧急中断仍使用现有停止任务操作。文档 OCR 独立选择及 low 保持不变；删除/停用其引用必须阻断。

## 界面

设置页改为供应商连接卡和模型列表，提供检测、搜索、多选添加、手动添加、每模型参数编辑。编辑供应商卡不自动切换聊天模型。检测响应绑定输入版本，过期结果不能覆盖新地址/Key 的状态。

聊天弹层独立组件：供应商分组模型列表、选中模型、离散思考滑条、恢复默认；收起显示供应商/模型与有效档位。保留上下文用量，不把它当思考百分比。兼容窄屏、深色、键盘和点击外部关闭。由用户验收前端，不运行构建或浏览器。
